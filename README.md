Overview
This project implements the classic Water Jug Problem, a well-known Artificial Intelligence problem that demonstrates state space search and logical reasoning. The objective is to measure a specific target amount of water using two jugs of fixed capacities and a limited set of operations.

---
## Problem Description
Two jugs with fixed capacities are given.
The jugs have no measurement markings.
An unlimited water supply is available.
The goal is to measure exactly the target amount of water.

Allowed Operations
Fill a jug completely.
Empty a jug completely.
Pour water from one jug to another until one jug is full or the other is empty.

State Representation
Each state is represented as an ordered pair:

(jug1, jug2)

Example:
(2, 1) represents 2 liters of water in Jug 1 and 1 liter in Jug 2.

Initial State
(0, 0)

Target State
Any state where either jug contains the target amount of water.
